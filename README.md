# Sprint_5
Проект содержит автоматизированные UI-тесты для веб-приложения **Stellar Burgers** с использованием Selenium WebDriver и Python.

## 📊 Покрытие тестами

### 🔐 Тесты аутентификации
- ✅ Успешная регистрация с валидными данными
- ❌ Ошибка при регистрации с некорректным паролем (менее 6 символов)
- 🔑 Авторизация через:
  - Кнопку на главной странице
  - Кнопку "Личный кабинет"
  - Ссылку в форме регистрации
  - Ссылку в форме восстановления пароля

### 👤 Тесты личного кабинета
- 🚪 Переход в личный кабинет
- 🏗️ Навигация из личного кабинета:
  - В конструктор через кнопку
  - На главную через логотип
- 🚪 Выход из аккаунта

### 🍔 Тесты конструктора
- 🥯 Раздел "Булки"
- 🧂 Раздел "Соусы"
- 🧀 Раздел "Начинки"

## 🛠️ Технологический стек

- **Python 3.x**
- **Selenium WebDriver**
- **Pytest** (тестовый фреймворк)
- **ChromeDriver** (для автоматизации в Chrome)
